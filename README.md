# Zepto Data & AI Platform

## Capstone Project

This project is developed as part of the Certificate Program in Artificial Intelligence and Machine Learning.

The goal of this capstone is to build an end-to-end Data and AI platform consisting of three connected modules:

1. **Data Pipeline** – Web scraping, data cleaning, SQL database creation, and querying.
2. **Analytics** – Exploratory data analysis, visualization, and machine learning.
3. **Support Assistant** – A GenAI-based assistant for answering policy-related questions using provided documents.

## Project Structure

```text
zepto-data-ai-platform/

```

## Modules

### 1. Data Pipeline

Collect and process book data from Books to Scrape, clean the extracted data, store it in a relational SQLite database, and perform SQL-based analysis.

### 2. Analytics

Perform end-to-end data analysis and machine learning on the provided dataset.

### 3. Support Assistant

Build a grounded GenAI assistant capable of answering questions based on provided policy documents.
